# Quiz App 

A responsive and interactive **Quiz Application** built with HTML, CSS, and JavaScript. Users can create an account, log in, attempt timed quizzes, and view their results.

## ✨ Features

* 🔐 Login & Signup
* 💾 Local Storage
* 📝 Interactive Quiz
* ⏱️ Countdown Timer
* 📊 Result & Score Display
* 🔔 SweetAlert2 Alerts
* 📱 Responsive Design
* 🚪 Logout Functionality

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage
* SweetAlert2

## 🎯 How It Works

1. Create an account using the Signup page.
2. Log in with your registered credentials.
3. Start the quiz.
4. Answer the questions before the timer ends.
5. Submit the quiz and view your final score.
6. Log out when you're done.
